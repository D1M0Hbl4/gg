## Введение

Учебная практика проходила на базе СПБГУГА и включала два основных направления деятельности. Первое направление — инженерно-техническая работа с аппаратно-программными средствами (АПС) беспилотных летательных аппаратов (БВС), включая изучение документации, техническое обслуживание, радиомонтаж, программирование и моделирование полётов. Второе направление — научно-исследовательская деятельность, связанная с изучением технологии гальванической вестибулярной стимуляции (ГВС) и её применением для повышения реалистичности авиационных тренажёров и симуляторов.

Цель практики — закрепление теоретических знаний, получение практических навыков эксплуатации АПС и проведение прикладных исследований в области нейрофизиологических методов улучшения качества симуляции.

### 6. Радиомонтаж. Основы пайки электронных компонентов

**Объект:** Учебный стенд и комплект электронных компонентов.

Изучены теоретические основы радиомонтажа:

- **Инструментарий:** паяльная станция (регулируемая температура 300–380 °C), припой (Sn60Pb40), флюс (канифоль, гель-флюс), пинцет, бокорезы, отсос для припоя, лупа.

- **Дефекты пайки:**
  - «Холодная» пайка (матовый цвет, шарообразная форма).
  - Перегрев и отслаивание печатных дорожек.

**Результат:** Освоены базовые навыки пайки, выполнены тренировочные упражнения на макетной плате.

### 12. Моделирование полёта квадрокоптера в системе координат ENU

**Объект:** Симулятор Gazebo.

Изучена система координат **ENU** (East-North-Up — Восток-Север-Вверх), используемая в ряде симуляторов и навигационных систем.

**Отличие от NED (North-East-Down):**
- В ENU ось Z направлена вверх, что удобно для наземных систем и визуализации.
- В NED ось Z направлена вниз, используется в авиации.

**Выполненные работы:**
- Настройка симулятора для отображения траектории в системе ENU.
- Преобразование координат из ENU в NED для совместимости с полётным контроллером.
- Визуализация полёта с отображением осей координат.

**Результат:** Освоена работа с различными системами координат, выполнено успешное моделирование с отображением траектории в ENU.

Проведён обзор литературы по теме гальванической вестибулярной стимуляции:

**Что такое ГВС:**
- Метод неинвазивной электростимуляции вестибулярного аппарата через электроды, размещаемые за ушами (в области сосцевидных отростков).
- Слабый электрический ток (0.5–4 мА) модулирует активность вестибулярных нервов, создавая иллюзию движения (наклона, вращения).

**Применение в авиационной сфере:**
- Улучшение пространственной ориентации лётчиков.
- Борьба с пространственной дезориентацией в сложных метеоусловиях.
- Повышение реалистичности тренажёров и симуляторов полёта.

### 20. Исследование физиологических эффектов ГВС на вестибулярную систему человека

**Объект:** Теоретические модели и экспериментальные данные (из литературных источников).

Изучены физиологические механизмы ГВС:

- ГВС воздействует на волосковые клетки вестибулярного аппарата, изменяя частоту импульсации вестибулярного нерва.
- Анодная стимуляция увеличивает частоту импульсов (возбуждение), катодная — уменьшает (торможение).
- Эффекты: ощущение наклона, вращения, смещения в зависимости от расположения электродов (билатеральная/монолатеральная стимуляция).
- Безопасность: ток до 5 мА не вызывает повреждений тканей при соблюдении временных режимов.

**Результат:** Сформировано понимание физиологических основ ГВС, определены безопасные параметры стимуляции.

### 23. Реализация прототипа алгоритма интеграции ГВС в архитектуру симулятора

**Объект:** Архитектура программного обеспечения симулятора.

Разработан алгоритм интеграции ГВС в симулятор (на примере симулятора полёта):

```
1. Симулятор вычисляет текущие параметры движения (ускорение, угловую скорость).
2. Параметры поступают в модель восприятия движения.
3. Модель определяет, какой сигнал ГВС необходим для имитации ощущения движения.
4. Сигнал преобразуется в параметры стимуляции (сила тока, частота, полярность).
5. Управляющий сигнал подаётся на устройство ГВС (электроды).
```

Прототип реализован на языке Python с использованием библиотек для численного моделирования (NumPy, SciPy) и интерфейса с симулятором через ROS.

**Результат:** Создан программный прототип, демонстрирующий возможность интеграции ГВС в архитектуру симулятора.
